# Tick Replay ปี 2025 และการเปลี่ยน TF

ใน **Backtest → Create โปรไฟล์** เลือก BTCUSD หรือ XAUUSD แล้วเลือกชุดข้อมูล **2025 · Real ticks · Dukascopy** ระบุเงิน/เป้าหมาย/มูลค่าต่อหนึ่งหน่วยราคาเหมือนเดิม โปรไฟล์ใหม่สุ่มจุดเริ่มทุกครั้ง พร้อมบริบทอย่างน้อย 20 แท่ง (250 เมื่อข้อมูลยาวพอ) และช่วงฝึกต่อ ส่วน Load คงเวลาเดิม เมื่อเปิดหน้าโปรไฟล์ให้ Refresh หนึ่งครั้งหลังนำเข้าชุดข้อมูลใหม่

ข้อมูลมาจาก [Dukascopy Historical Price Data](https://www.dukascopy.com/wiki/en/development/data-export/) เป็น Bid/Ask ของ Dukascopy ไม่ใช่ BTCUSDc/XAUUSDc ของ Exness ราคา สเปรด และช่วงเปิดตลาดอาจต่างกัน รายงานในไฟล์ `data/market-data/<ชุดข้อมูล>/manifest.json` เก็บวันที่ตรวจแล้ว วันที่ไม่มี archive จำนวน quote ช่วงเวลาจริง และ checksum ข้อมูลไม่ได้เข้า Git

## ใช้งาน

- เลือก **M1 / M5 / M15 / M30 / H1 / H4 / D1** บนแถบกราฟ ทุก TF ใช้ quote และเวลา Replay เดียวกัน เปลี่ยน TF ไม่ขยับเวลา ไม่เข้า/ออก Position และไม่แก้หลักฐานการเข้าไม้
- **เล่น Replay** เดินตาม timestamp จริง แท่งปัจจุบันเปลี่ยน Open/High/Low/Close จาก tick ที่เปิดเผยแล้ว ความเร็ว 0.5×–240× หมายถึงอัตราเวลาในข้อมูลต่อเวลาเล่น ระบบอาจเดินช้าลงหากเครื่องประมวลผลไม่ทัน
- **ทีละ Tick** เปิดเผย quote ถัดไปหนึ่งรายการ หากหลาย quote อยู่ในมิลลิวินาทีเดียวกันก็ยังเรียงตามลำดับเดิม
- **ย้อนแท่ง** กลับไป quote สุดท้ายของแท่งก่อนหน้าใน TF ที่เลือก (ถ้าไม่มีแท่งก่อนหน้า กลับต้นข้อมูล) หยุดการเล่นและยกเลิก Position จำลองที่ยังเปิดหรือรอเข้าอยู่ ไม้ที่ปิดแล้ว ผล กำไรสะสม และ Review ยังอยู่ เริ่มฝึกไม้ใหม่จากจุดที่ย้อนได้
- **ทีละแท่ง** เดินผ่าน tick จนถึง quote แรกของแท่งถัดไปใน TF ที่เลือก ถ้าชน TP/SL จะหยุดที่ tick ที่ออกก่อน
- ช่วงที่ไม่มี quote ยาวตั้งแต่ 15 นาทีจะข้ามไป quote จริงถัดไป ช่วงพักสั้นกว่านั้นเวลาเดินตามอัตราเล่นและคงราคาล่าสุด ไม่สร้างราคาคั่นกลาง แท่งที่ยังไม่ปิดมีเฉพาะ High/Low/Volume ถึงเวลาที่เห็น อินดิเคเตอร์จึงขยับระหว่างแท่งได้และค่าก่อนแท่งปิดยังเปลี่ยนได้
- เลื่อนและซูมกราฟ วาดเส้น/Zone/Fibo และเพิ่มอินดิเคเตอร์เองได้เหมือนเดิม ภาพวาดคงราคา/เวลาต้นฉบับเมื่อเปลี่ยน TF จุดเวลาแสดงในแท่งที่ครอบคลุมเวลานั้น หากสองจุดอยู่แท่งเดียวกัน เส้นจะยุบใน TF นั้น กลับ TF เดิมเพื่อเห็นทั้งสองจุด

เซิร์ฟเวอร์ส่งกราฟย้อนหลังได้สูงสุด **2,000 แท่งของ TF ที่เลือก** ต่อหน้าต่าง เพื่อไม่ส่งข้อมูล tick ทั้งปีให้เบราว์เซอร์ อินดิเคเตอร์คำนวณจากหน้าต่างนี้ ค่า EMA/RSI ที่ใช้ period ยาวอาจต่างจากการคำนวณที่มีประวัติตั้งแต่ต้นปี เลือก TF ใหญ่ขึ้นเพื่อดูบริบทกว้างขึ้น หรือสร้างโปรไฟล์ใหม่เพื่อสุ่มช่วงเริ่มเพื่อฝึกช่วงอื่นในปี ย้อนกราฟรอบเดิมได้ โดยผลของไม้ที่ปิดแล้วยังคงอยู่และแต่ละการย้อนมีเลขรอบย่อยกำกับการเข้าใหม่ ผลการฝึกที่ย้อนซ้ำจึงไม่ใช่การทดสอบแบบเห็นราคาเพียงครั้งเดียว

## Position จำลองจาก Bid/Ask

Market รอ quote ถัดไป Buy เปิดที่ Ask/ปิดที่ Bid; Sell เปิดที่ Bid/ปิดที่ Ask ใช้สเปรดจริง จึงไม่ใช้ช่อง Spread คงที่ของโปรไฟล์ tick Limit รอ quote ฝั่งเข้าแตะระดับและได้ราคาที่ดีขึ้นเมื่อ gap; Stop เข้า quote ที่ข้ามระดับ จึงได้ราคาที่แย่ลงได้ หาก fill อยู่นอกกรอบ SL/TP จะยกเลิกคำสั่ง

SL ปิดตาม quote จริงที่แตะหรือข้าม Stop จึงขาดทุนเกิน 1R ได้ TP แบบ limit คิดที่ราคาเป้าหมายเพื่อไม่เพิ่มกำไรจาก gap ระบบตรวจแต่ละ quote ตามลำดับ จึงไม่ใช้สมมติฐาน SL ก่อนของ OHLC ปิดมือใช้ Bid/Ask ล่าสุดที่เห็น มิลลิวินาทีและลำดับ quote ที่เข้า/ออกเก็บใน decision แยกจาก timestamps วินาทีเดิม

เปิดหลาย Position ได้ แยกปิดแต่ละไม้ด้วย × บนกราฟ หรือปิดบางส่วนตาม Lot ในตาราง กำไร/ขาดทุนลอยตัวแสดงตาม Bid/Ask ของ quote ล่าสุดเฉพาะ Lot คงเหลือ; ส่วนที่ปิดแล้วรับรู้เข้า Balance ทันที รวมผลเป็นไม้เดิมเมื่อปิดทั้งหมด ระบบประมวลผลทุก Position ที่ quote เดียวกัน ไม่หยุดตรวจหลังไม้แรก การปิดแสดง toast โดยไม่บังคับเปิด Review หรือหยุด Play

ยังเป็นการฝึกจำลอง: ไม่จำลอง queue/depth การเติมสภาพคล่อง latency broker swap margin หรือ partial fills จากสภาพคล่อง ไม่มีคำสั่งซื้อขายจริง แอป standalone ไม่อ่านหรือเขียน Journal ของ TradeQuest มูลค่าต่อหนึ่งหน่วยราคา/Lot และสกุลเงินยังต้องกำหนดเอง ไม่ยืมสเปกบัญชี Exness ไปใช้กับ feed อื่น

CSV/ช่วงกราฟ MT5 เดิมยังใช้ **Bar Replay** ไม่มี tick จริงให้เล่น เพิ่ม TF ที่ใหญ่กว่าหรือเท่ากับไฟล์ต้นฉบับได้ แต่เลือก TF ที่เล็กกว่าไม่ได้ ระบบไม่สร้าง tick หรือแท่งย่อยจาก OHLC

## สำหรับเพื่อนที่ Clone Repo

จาก root ของ repo standalone หลังติดตั้ง dependencies และเริ่มแอปหนึ่งครั้งตาม README:

```bash
python3 scripts/download_ticks.py --year 2025 --symbols BTCUSD XAUUSD --workers 4
PYTHONPATH=apps/api apps/api/.venv/bin/python scripts/import_tick_archives.py --year 2025
```

ดาวน์โหลดเป็น archive รายวัน UTC วันที่ 1 มกราคม 2025 ถึงก่อน 1 มกราคม 2026 รันซ้ำได้โดยใช้ cache เดิม มี retry เมื่อ timeout/503/429 ไม่สมัครบริการหรือใช้ AWS Requester Pays หากดาวน์โหลดบางวันผิดพลาด เครื่องมือนำเข้าจะปฏิเสธชุดข้อมูลทั้ง Symbol จนตรวจครบปี วันที่ผู้ให้ข้อมูลตอบ 404 หรือ archive ว่างถูกบันทึกเป็น “ไม่มีข้อมูลจากแหล่งราคา” ไม่รับรองเองว่าทุกกรณีคือวันหยุด

เครื่องมือนำเข้าตรวจ checksum ทุก archive, ลำดับเวลา, ขนาด record, ราคาบวก, Ask ≥ Bid และ volume ใช้ scale BTCUSD=10, XAUUSD=1000 ตาม priceScale 1/3 ของ instrument metadata และเก็บแหล่งอ้างอิงไว้ใน manifest เก็บ tick แบบ binary 24 bytes/quote พร้อมดัชนี SQLite ของกราฟ แยกจากฐานโปรไฟล์หลัก ชุดข้อมูลที่ลงทะเบียนแล้วใช้ไฟล์ immutable ไม่แก้เก่าเพื่อให้ผลฝึกเปลี่ยนตาม
